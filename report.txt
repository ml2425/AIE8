# LangGraph MCP Agent - Complete User Guide

## 🚀 Quick Start

This project provides a **natural language interface** to MCP (Model Context Protocol) server tools. You can interact with weather, dice rolling, and web search functionality through conversational queries.

### Prerequisites
- Python 3.13+
- Virtual environment activated
- Tavily API key (for web search)

### Installation
```bash
# Clone the repository
git clone <repository-url>
cd AIE8-MCP-Session

# Activate virtual environment
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac

# Install dependencies
uv sync
```

### Environment Setup
Create `.env` file:
```env
TAVILY_API_KEY=your_tavily_api_key_here
```

## 🛠️ Available Tools

### MCP Server Tools (`server.py`)
Your MCP server exposes **5 tools**:

1. **`web_search`** - Search the web for information
2. **`roll_dice`** - Roll dice with various notations
3. **`geo_lookup`** - Convert place name to coordinates
4. **`get_weather`** - Get weather for specific coordinates
5. **`weather_by_place`** - One-call weather for any place name

### LangGraph Agent Tools (`langgraph_agent.py`)
The agent supports **3 tools** with natural language:

1. **Weather** - Ask about weather in any city
2. **Dice Rolling** - Roll dice with notation
3. **Web Search** - Search the web for information

### Method 2: Direct MCP Server Access

**Access MCP tools directly:**
```python
from fastmcp import Client
import asyncio

async def direct_access():
    async with Client("server.py") as client:
        # List available tools
        tools = await client.list_tools()
        print("Available tools:", [tool.name for tool in tools])
        
        # Call weather tool
        result = await client.call_tool("weather_by_place", {"place": "Paris"})
        print("Weather:", result)
        
        # Call dice tool
        result = await client.call_tool("roll_dice", {"notation": "3d6", "num_rolls": 1})
        print("Dice:", result)

asyncio.run(direct_access())
```

### Method 3: Programmatic LangGraph Agent

**Use the agent in your code:**
```python
from langgraph_agent import MCPAgent
import asyncio

async def use_agent():
    agent = MCPAgent()
    
    # Ask questions programmatically
    response = await agent.run("What's the weather in London?")
    print(response)
    
    response = await agent.run("Roll 4d6")
    print(response)

asyncio.run(use_agent())
```

## 🔧 Technical Details

### Architecture
```
User Input → LangGraph Agent → REGEX Classification → MCP Tool Call → Response Formatting
```

### Intent Classification (REGEX-based)
The agent uses regex patterns to understand your queries:

**Weather patterns:**
- `r"weather.*in\s+(\w+)"` - "weather in Paris"
- `r"what.*weather.*(\w+)"` - "what weather in Tokyo"

**Dice patterns:**
- `r"roll\s+(\d+d\d+(?:k\d+)?)"` - "roll 3d6"
- `r"(\d+d\d+(?:k\d+)?)"` - "3d6"

**Search patterns:**
- `r"search\s+for\s+(.+)"` - "search for Python"
- `r"what\s+is\s+(.+)"` - "what is AI"

### MCP Integration
- **Transport**: stdio (local process communication)
- **Client**: `fastmcp.Client`
- **Server**: `server.py` with FastMCP
- **Tools**: 5 MCP tools available

## 🔍 Troubleshooting

### Common Issues

**1. ModuleNotFoundError: No module named 'fastmcp'**
```bash
# Solution: Activate virtual environment

```

**2. Tavily API Key Error**
```bash
# Solution: Add API key to .env file
echo "TAVILY_API_KEY=your_key_here" > .env
```

**3. Unknown Intent Response**
```

```
**Solution**: Use supported query patterns (weather, dice, search)

## 📊 Performance

### REGEX vs LLM Comparison
| Aspect | Current (REGEX) | LLM-Based |
|--------|----------------|-----------|
| **Speed** | ✅ Very fast | ⚠️ Slower (API calls) |
| **Cost** | ✅ Free | ❌ Costs money |
| **Accuracy** | ⚠️ Limited patterns | ✅ More flexible |
| **Maintenance** | ❌ Need to add patterns | ✅ Learns from examples |

### Response Times
- **Weather queries**: ~2-3 seconds
- **Dice rolling**: <1 second
- **Web search**: ~3-5 seconds

## 📚 API Reference

### MCPAgent Class
```python
class MCPAgent:
    def __init__(self):
        """Initialize the LangGraph agent"""
    
    async def run(self, user_input: str) -> str:
        """Process user input and return response"""
    
    def classify_intent(self, state: AgentState) -> AgentState:
        """Classify user intent using regex patterns"""
    
    async def call_mcp_tool(self, state: AgentState) -> AgentState:
        """Call appropriate MCP tool based on intent"""
    
    def format_response(self, state: AgentState) -> AgentState:
        """Format tool result for user display"""
```

### MCP Server Tools
```python
# Weather tools
weather_by_place(place: str) -> dict
get_weather(lat: float, lon: float, summarize: bool = True) -> dict
geo_lookup(place: str) -> dict

# Utility tools
roll_dice(notation: str, num_rolls: int = 1) -> str
web_search(query: str) -> str
```

## 🤝 Contributing

### Adding New Tools
1. **Define tool in `server.py`**:
```python
@mcp.tool()
def my_new_tool(param: str) -> str:
    """Description of what the tool does"""
    return "Tool result"
```

2. **Add patterns to `langgraph_agent.py`**:
```python
# Add to classify_intent()
my_tool_patterns = [
    r"pattern.*for\s+(.+)",
]

for pattern in my_tool_patterns:
    match = re.search(pattern, user_input)
    if match:
        return {
            **state,
            "intent": "my_tool",
            "extracted_params": {"param": match.group(1)}
        }
```

3. **Add tool calling**:
```python
# Add to call_mcp_tool()
elif intent == "my_tool":
    result = await client.call_tool("my_new_tool", params)
    tool_result = str(result)
```

4. **Add response formatting**:
```python
# Add to format_response()
elif intent == "my_tool":
    final_response = f"My tool result: {tool_result}"
```
